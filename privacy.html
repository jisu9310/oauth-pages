개인정보처리방침

최종 수정일: 2026년 8월 29일

이 문서는 채널 운영 자동화 도구가 구글 계정 데이터를 어떻게 다루는지 설명합니다. 이 도구는 운영자 본인이 자신의 계정과 자신이 소유한 채널에만 사용하는 개인용 도구이며, 일반 이용자를 대상으로 서비스를 제공하지 않습니다.

수집하는 정보

운영자가 구글 계정으로 인증을 승인한 범위 안에서 다음 정보에 접근합니다.

  • 운영자 본인이 소유한 유튜브 채널의 공개 지표와 애널리틱스 보고서
  • 운영자가 지정한 구글 스프레드시트의 내용
  • 운영자가 이 도구로 생성하거나 지정한 구글 드라이브 파일
  • 운영자 본인의 구글 캘린더 일정
  • 운영자 본인의 지메일 메시지
  • 인증된 계정을 식별하기 위한 이메일 주소

이용 목적

수집한 정보는 운영자 본인의 채널 운영과 콘텐츠 관리를 자동화하는 목적으로만 사용합니다. 광고, 프로파일링, 판매, 학습 데이터 등 다른 목적으로 사용하지 않습니다.

저장과 보관

  • 인증 토큰은 운영자의 개인 PC에 파일 시스템 암호화가 적용된 폴더에 저장됩니다.
  • 수집한 지표는 운영자 본인의 구글 스프레드시트에 기록됩니다.
  • 별도의 서버나 데이터베이스로 데이터를 전송하지 않습니다.

제3자 제공

어떤 데이터도 제3자에게 제공, 판매, 공유하지 않습니다. 데이터는 운영자의 구글 계정과 운영자의 개인 PC를 벗어나지 않습니다.

구글 사용자 데이터 정책

이 도구는 구글 API 서비스 사용자 데이터 정책을 준수하며, 여기에는 제한적 사용 요건이 포함됩니다.

접근 권한 철회

운영자는 언제든지 구글 계정 권한 페이지에서 이 도구의 접근 권한을 철회할 수 있습니다. 철회하면 저장된 토큰은 즉시 무효가 되며, 운영자가 로컬에 보관 중인 토큰 파일을 삭제하면 남은 자료도 사라집니다.

문의

이 방침에 대한 문의는 이 도구의 운영자에게 직접 해주시기 바랍니다.
