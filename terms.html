서비스 약관

최종 수정일: 2026년 8월 29일

이 약관은 채널 운영 자동화 도구의 이용 조건을 정합니다. 이 도구는 운영자 본인이 자신의 구글 계정과 자신이 소유한 채널에만 사용하는 개인용 스크립트이며, 일반 이용자를 대상으로 제공하는 서비스가 아닙니다.

이용 범위

  • 이 도구는 운영자 본인만 사용합니다.
  • 운영자가 구글 계정으로 직접 승인한 범위 안에서만 동작합니다.
  • 회원 가입, 로그인, 결제 같은 절차가 없으며 제공되는 대가도 없습니다.

운영자의 책임

운영자는 이 도구를 구글 API 서비스 약관과 관련 법령을 지키는 범위에서 사용합니다. 승인받은 범위를 넘는 접근을 시도하지 않으며, 타인의 계정이나 데이터에 사용하지 않습니다.

보증하지 않는 것

이 도구는 개인용 스크립트로 있는 그대로 제공됩니다. 구글 API 사양 변경, 할당량 초과, 네트워크 장애 등으로 동작이 중단될 수 있으며 무중단 동작을 보증하지 않습니다. 수집한 지표의 정확성은 구글이 제공하는 원본 데이터에 따릅니다.

이용 중단

운영자는 언제든지 구글 계정 권한 페이지에서 접근 권한을 철회해 이 도구의 동작을 중단시킬 수 있습니다.
