채널 운영 자동화 도구

유튜브 채널과 콘텐츠 운영을 위한 개인용 자동화 스크립트입니다.

무엇을 하는 도구인가요

운영자 본인이 소유한 유튜브 채널의 성과 지표를 정기적으로 수집해 구글 스프레드시트에 기록하고, 영상 업로드와 메타데이터 관리를 돕는 개인용 도구입니다. 운영자 한 사람이 자신의 계정과 자신의 채널에만 사용하며, 다른 이용자에게 서비스로 제공하지 않습니다.

주요 기능

  • 본인 채널의 조회수, 구독자수, 영상별 지표 수집
  • 유튜브 애널리틱스 보고서 조회 (노출수, 클릭률 등)
  • 수집한 지표를 구글 스프레드시트에 기록
  • 영상 업로드 및 설명란, 태그 등 메타데이터 관리
  • 운영 일정과 메일 정리

사용하는 구글 API

  • YouTube Data API v3
  • YouTube Analytics API
  • Google Sheets API
  • Google Drive API
  • Google Calendar API
  • Gmail API

구글 계정 데이터 사용

이 도구는 운영자 본인의 구글 계정으로만 인증하며, 인증 토큰은 운영자의 개인 PC에 암호화되어 저장됩니다. 수집한 데이터는 외부로 전송되거나 제3자에게 제공되지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

문의: 이 도구의 운영자에게 직접 문의해 주세요.
